Vue 2 Limitations:

  • Object.defineProperty - must walk all properties at init
  • Cannot detect property additions/deletions (need Vue.set)
  • Cannot detect array index changes directly
  • All global APIs bundled regardless of usage
  • No tree-shaking: v-model, transition, keep-alive always included
  • Mixins: implicit dependencies, namespace conflicts
  • Single root element required per component
